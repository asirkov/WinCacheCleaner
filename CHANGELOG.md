# Історія змін

## 0.3.1

### Запуск одним файлом

Додано **WinCacheCleaner.cmd**: завантажте його з Assets і запустіть подвійним
кліком. Окремий `.ps1` чи інсталяція не потрібні — достатньо вбудованого Windows
PowerShell 5.1. Меню вибору та підтвердження очищення залишаються такими самими.

- `WinCacheCleaner.cmd -AnalyzeOnly` — переглянути знайдені кеші без видалення.
- `WinCacheCleaner.cmd -Version` — показати версію.
- ZIP містить CMD, початковий PowerShell-скрипт, інструкцію та SHA256 для перевірки файлів.

### Публікація релізів

Виправлено помилку GitHub Actions із вибором оболонки. Перед публікацією
перевіряються версія, синтаксис, захист тестових даних і запуск CMD на Windows.
Релізні пакети збираються лише з `main`; `develop` запускає перевірки коду.
Нотатки релізу тепер беруться з цієї історії змін, а не зі списку коммітів.

### Що варто знати

CMD не надає адміністративних прав автоматично й не змінює політику виконання.
Перед очищенням закрийте відповідні програми. Залишки видалених програм усе ще
визначаються приблизно: перевіряйте вибрані шляхи перед підтвердженням.

## 0.3.0

### Вибіркове очищення кешів

Додано опціональне очищення кешів **Chrome, Edge і Firefox**. Ця опція вимкнена
за замовчуванням; потрібно обрати конкретні кеші та закрити браузер. Cookies,
паролі, історія, закладки й сесії не входять до цілей очищення.

Додано пошук можливих залишків програм в AppData та ProgramData. Скрипт пропонує
лише відомі кеш-папки й тимчасові файли старше 30 днів, а не всю папку програми.
Видалення потребує ручного вибору, підтвердження `LEFTOVERS`, а потім `CLEAN`.
Відсутність програми в реєстрі не доводить, що її дані непотрібні.

### Аналіз без змін

Параметр `-AnalyzeOnly` показує знайдені кандидати без очищення та запису звітів.
Додано тести, які перевіряють збереження cookies, збережень ігор, свіжих файлів
та пропуск символьних посилань. Версію можна переглянути параметром `-Version`.

### Обмеження

Розміри кандидатів показані як логічний розмір файлів, а не фізично зайняте місце.
Нестандартні шляхи portable-браузерів не визначаються. Очищення Windows Update,
Docker/WSL та кешів розробника в цій версії ще не реалізоване.
